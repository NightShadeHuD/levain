# T-2: number format and costs

- **Risk:** low.
- **Reads:** SPEC.md section 4, row T-2; criteria AC-6, AC-7, AC-58; docs/GAME-DESIGN.md sections 3.4 and 17;
  src/core/rng.ts (for the house style).
- **May change:** src/core/format.ts, src/core/cost.ts, src/core/data.ts, test/format.test.ts, test/cost.test.ts.
- **Build:** `format.ts` turns a number into the text the screen shows; `cost.ts` gives the cost of the next
  one, the cost of n more, and the most that can be bought.
- **How:**
  - `formatAmount(x)`: rounds down. Plain with no decimals up to 999,999 (`999999` shows `999,999`). From a
    million: three significant figures and a suffix: K is never used above a million (`1,000,000` shows
    `1.00M`). The suffixes, in data.ts: M, B, T, Qa, Qi, Sx, Sp, Oc, No, Dc. Above Dc (1e36 and up):
    scientific, `1.23e36`. `formatAmount(x, "scientific")` is scientific from 1,000 up.
  - `formatCost(x)`: the same, but rounds up: `1.231M` of cost shows `1.24M`; `999,999.2` shows `1.00M`.
  - Small numbers: `formatAmount(0.7)` shows `0`; `formatCost(0.2)` shows `1`.
  - `costOf(base, factor, owned)` = `base × factor^owned`.
  - `costOfN(base, factor, owned, n)` = the sum of n single costs, by the geometric series
    `base × factor^owned × (factor^n − 1) / (factor − 1)`.
  - `maxAffordable(base, factor, owned, have)`: the largest n with `costOfN ≤ have`, exact for n up to
    10,000 (check the result and the result + 1 with costOfN, so rounding never gives one too many).
  - `canAfford(have, cost)` compares the exact numbers, never the shown text (design 3.4).
  - Every constant (the suffix list, the thresholds) lives in src/core/data.ts.
- **Done means:** `npx vitest run -t "format: numbers match the table"`,
  `npx vitest run -t "cost: buying n at once costs the same as n single buys"`,
  `npx vitest run -t "format: costs round up, amounts down, affordability is exact"`, `npx tsc --noEmit`,
  `bash tests/gates.sh`.
- **Breaks** (one per line, given to the gates as `BREAKS='<line>'` and to the commit as `Breaks: <line>`):
