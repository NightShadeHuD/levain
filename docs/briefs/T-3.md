# T-3: the game state, the step and Feed

- **Risk:** medium (every later task builds on this shape).
- **Reads:** SPEC.md section 4, row T-3; criteria AC-8, AC-9, AC-13, AC-56, AC-77; docs/GAME-DESIGN.md sections
  3.1, 3.2, 3.3, 3.4, 4.1 and 4.3 (the Feed line only); src/core/rng.ts; src/core/data.ts.
- **May change:** src/core/state.ts, src/core/step.ts, src/core/actions.ts, src/core/bonus.ts,
  src/core/data.ts, test/state.test.ts, test/bonus.test.ts, test/feed.test.ts.
- **Build:** the plain-data game state, a new game, the fixed-step clock and the Feed action. No jobs, growth,
  buildings or research yet: later tasks add them to this shape.
- **How:**
  - `GameState` is plain data only (numbers, strings, booleans, arrays, plain objects), so `JSON.stringify`
    and `structuredClone` copy it exactly. Fields now: `version` (1), `saveCounter` (0), `rng` (the Rng from
    rng.ts), `time` (game seconds since the batch began), `resources` (`flour`, `sugar`, `rise`, `tang`,
    `murmurs`, `crackers`, all numbers), `cells` (10), `housing` (10), `flourCap` (500), `research` (a list of
    names, empty), `feedsThisSecond` (0), `feedSecond` (0), `tallies` (`devotion`, `thought`, `valour`, all 0).
  - `newGame(seed)` returns that state with `rng = makeRng(seed)`.
  - `step(state, seconds)` advances in whole steps of 0.1 s (`STEP_SECONDS` in data.ts). A remainder under
    0.1 s is carried in `state.carry` (add the field), never lost and never run early. A negative or NaN
    `seconds` does nothing. In this task a step only advances `time`; later tasks add work inside it, in the
    order of design 3.2.
  - `feed(state)`: adds `FEED_FLOUR` (5) flour, ×2 if `research` includes "Autolyse"; never above
    `flourCap`; adds 1 to `tallies.devotion`. At most `FEED_MAX_PER_SECOND` (10) feeds count in one whole
    game second (`Math.floor(time)`); further feeds in that second change nothing (design 4.3). Write the check as exactly
    `if (state.feedsThisSecond >= FEED_MAX_PER_SECOND) return;`
  - `bonus.ts`: `combine(sources)` takes a list of `{ source, percent }` and returns the final multiplier:
    percents add within the same source; each source gives `Math.max(0.1, 1 + sum / 100)` (written exactly so,
    once); the sources multiply.
  - `guard(state)`: every resource, `cells`, `housing` and `flourCap` must be finite and not negative;
    NaN or a negative becomes 0 and anything above `VALUE_CAP` (1e300) becomes 1e300. `step` calls it at the
    end of every step.
  - No document, window, Date, Math.random or localStorage in src/core. Every number in data.ts.
- **Done means:** `npx vitest run -t "step: same seed and same actions give the same state"`,
  `npx vitest run -t "step: no amount is ever NaN, infinite or negative"`,
  `npx vitest run -t "feed: one feed adds 5 flour, 10 after Autolyse"`,
  `npx vitest run -t "bonuses: sources add within and multiply across"`,
  `npx vitest run -t "feed: at most 10 feeds a second count"`, `npx tsc --noEmit`, the gates.
  The NaN test must feed `step` a state holding NaN, -5 and Infinity and see 0, 0 and 1e300 after one step.
