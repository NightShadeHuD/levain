# T-6: jobs

- **Risk:** low.
- **Reads:** SPEC.md section 4, row T-6; criteria AC-15, AC-16, AC-55, AC-76; docs/GAME-DESIGN.md sections 3.2
  and 4.3; src/core/state.ts, src/core/step.ts, src/core/growth.ts, src/core/data.ts.
- **May change:** src/core/jobs.ts, src/core/step.ts, src/core/growth.ts, src/core/state.ts, src/core/actions.ts,
  src/core/data.ts, test/jobs.test.ts.
- **Build:** the six jobs, assigning cells to them, their rates, and sharing sugar.
- **How:**
  - `state.jobs`: `miller`, `ponderer`, `enzymer`, `fermenter`, `sourer`, `guard`, each a whole number.
    `assign(state, job, n)` sets a job's number; it is refused (state unchanged) if the job is not unlocked
    (design 4.3 "Needs": Enzymer needs Diastase, Fermenter Fermentation, Sourer Symbiosis, Guard Acid Wall) or if
    the jobs would need more cells than there are. Idle = cells − all jobs except guard − the squad (0 for now).
  - Rates per cell per second, from the design's table, in data.ts. A step runs design 3.2 in order: Millers
    and Ponderers; Enzymers (limited by the flour there is); then sugar sharing.
  - **Sugar sharing (AC-55):** growth, Fermenters and Sourers each ask for sugar. If the sugar there is is less
    than the total asked, each gets `sugar / total` of its ask (written exactly `const share = Math.min(1, sugar / total);`, once), and makes that fraction of its output.
  - Caps: flour and sugar above `flourCap` are lost.
  - **After losses (AC-76):** `fitJobs(state)` cuts jobs when cells are fewer than the jobs need, in this order:
    ponderer, sourer, fermenter, enzymer, miller, kept in data.ts as exactly
    `export const CUT_ORDER = ["ponderer", "sourer", "fermenter", "enzymer", "miller"] as const;`. The guard number is never cut. step.ts calls it each step.
  - The Thought tally: `tallies.thought` grows by murmurs made ÷ 10.
- **Done means:** `npx vitest run -t "jobs: a job with no input makes nothing"`,
  `npx vitest run -t "jobs: rates match the table"`, `npx vitest run -t "step: short sugar is shared in proportion"`,
  `npx vitest run -t "jobs: after losses, jobs are cut in the set order"`, `npx tsc --noEmit`, the gates.

