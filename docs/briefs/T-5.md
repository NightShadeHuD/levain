# T-5: cells, growth and housing

- **Risk:** low.
- **Reads:** SPEC.md section 4, row T-5; criterion AC-14; docs/GAME-DESIGN.md sections 3.2 and 4.2;
  src/core/state.ts, src/core/step.ts, src/core/data.ts.
- **May change:** src/core/growth.ts, src/core/step.ts, src/core/state.ts, src/core/data.ts, test/growth.test.ts.
- **Build:** idle cells divide, eating sugar, up to the housing cap.
- **How:**
  - Idle cells = `cells` minus every cell with a job (no jobs exist yet: all cells are idle; T-6 adds jobs).
  - The room left is written exactly `const room = Math.max(0, state.housing - state.cells);`, once.
  - Growth asked per second = `GROWTH_RATE (0.05) × idle × growthMult`, never more than `housing − cells`.
    `growthMult` is 1 for now. Each new cell costs `BIRTH_SUGAR` (0.2) sugar.
  - In this task growth is the only sugar user. Write it as a request (`{ sugar: asked }`) that step.ts
    pays, so T-6 can share sugar between growth and jobs (design 3.2, step 3) without rewriting this.
  - With no sugar, nothing grows. With sugar for only part, that part grows. Fractions of a cell are kept.
  - `cells` never goes above `housing`, and never below 0.
- **Done means:** `npx vitest run -t "growth: idle cells divide only with sugar and below the cap"`,
  `npx tsc --noEmit`, the gates. The test covers: no sugar (no growth), full housing (no growth),
  half the sugar asked for (half the growth), and a step that would pass the cap (stops exactly at it).
- **Breaks:**

```
growth: idle cells divide only with sugar and below the cap fails when src/core/growth.ts has `state.housing - state.cells` as `state.housing - state.cells + 1`
```
