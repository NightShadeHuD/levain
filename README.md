# Levain

*A civilization rises in a jar of sourdough starter.*

Levain is a small, deep idle game for the browser. You are the Hand that feeds the jar. Inside it, the
cells farm the flour that falls from the sky, build bubbles to live in, and sour their walls against the
mold kingdoms in the fridge. When a civilization peaks, you bake it, and a spoonful of Mother starts the
next one, stronger than the last.

It is being built in the open, task by task, by AI coding agents (mostly local models in Kilo Code)
working under a set of checks. Nothing is playable yet. The design is in
[docs/GAME-DESIGN.md](docs/GAME-DESIGN.md), and the plan is in [SPEC.md](SPEC.md).

## Run it

```
npm ci
npm run dev
```
